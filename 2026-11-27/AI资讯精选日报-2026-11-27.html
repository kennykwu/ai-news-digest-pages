AI 硬件与端侧安全Calif 研究 · 页面署名 11 月 26 日

Samsung Knox DualDAR 双漏洞链可从零权限应用取得 Galaxy 旗舰 root

安全研究团队 Calif 发布《OEMpocalypse Part 2》：利用 Knox DualDAR 系统服务的「迷惑授权」缺陷获得特权守护进程内的代码执行，再利用内核驱动中「释放页仍保留映射」的 UAF 缺陷，实现任意内核读写，最终在引导加载器锁定的量产机上取得 root。作者在 Galaxy S23、S26 EU、S26 US、S26 Ultra 四款实测设备上以单一代码库稳定复现；静态分析提示其他骁龙/Exynos 平台的 S/Z 系列也受影响。已在 Hexacon 2026 演讲。

三星已修复：漏洞一在 2026 年 8 月补丁、漏洞二在 9 月补丁，跟踪为 CVE-2026-21102 / SVE-2026-3092。对普通用户的实际风险取决于是否及时更新系统。

为什么推给你：端侧设备的安全底座比演示能力更决定企业落地边界——Knox 长期被视为 Android 阵营最强加固层，其被链路级穿透说明「硬件可信」需要按补丁节奏动态评估。做 AI 硬件、随身秘书方向时，OEM 定制内核的驱动攻击面值得进入选型清单。建议关注 OEM 补丁月更与实际覆盖率的差距。

隐私与安全研究Calif 研究 · 页面署名 11 月 26 日

Tor Browser 15.0.22 默认配置可被恶意页面去匿名化，泄露真实 IP

Calif 发布《TORtilla with Onion》：在 Tor Browser 15.0.22 默认设置下，恶意网站经四阶段漏洞链——Gecko/Firefox 的 ReadableStream BYOB 跨窗口 UAF（CVE-2026-92027）取得受控内存读写，渲染进程内 ROP 伪造带 System 权限的历史记录，触发特权 DevTools 页面直接建连，最终在服务器侧 accept() 到用户真实公网 IP。链仍在内容沙箱内运行，未做父进程代码执行；需用户点击一次页面按钮。

该研究属 OpenAI「Patch the Planet」计划。匿名性依赖「浏览器不越过 Tor 建连」这条应用边界，本链正是击穿该边界，而非破解 Tor 网络本身。

为什么推给你：浏览器安全边界被穿透的方式，对任何把「可信执行位置」押在客户端架构上的产品设计都是提醒。与跨 Agent 记忆主线相关：当 Agent 承载用户身份与上下文时，出口通道本身的匿名与隔离假设需要独立验证。可作技术储备关注，暂无行动项。

《Why I'm Bullish on MCP for 2027》：一手反方观点，回应「Skills/CLI 取代 MCP」

前 Hugging Face 技术负责人、现 Google DeepMind 的 Philipp Schmid 发文，明确表态看好 MCP 进入 2027。他引用的一线数据：Linear 与 Notion 约一半 issue（约 240 万/周）和页面由 Agent 创建，Notion 报告 MCP 流量增长 60 倍；Atlassian 每个工作日经 MCP 处理超 500 万次工具调用，其中 44% 用户来自非软件团队；Neon 的 MCP 智能体用量周环比 +14%；Apple 已为 Pages/Numbers/Keynote 内置本地 MCP 服务器。他认为争议将被 Code Mode 终结：把 MCP 工具暴露为可编程函数，模型一个脚本串联多次调用，避开上下文膨胀这一 MCP 最大抱怨。这与 11-25 期「Skills over MCP」一文构成正反方。

文中增长数字均引自各公司公开资料，非作者独立测量；作者立场是预测，不是既成事实。

为什么推给你：这条直接落在跨 Agent 工具接入选型上。你的工作台要同时接 OpenViking、MCP 服务与本地 CLI，「MCP 供连接、Code Mode 供编排、CLI 供兜底」正在成为共识结构，不必在两者间做排他押注。建议把「工具以函数形态进入沙箱、模型写脚本链式调用」作为 DS Bot / OpenViking 链路演进的参照，重点验证 outputSchema 回传结构化数据对上下文占用的实际压缩。

支付宝 SkillPay 实测：把 Agent Skill 挂上去卖钱

数字生命卡兹克发布对支付宝 SkillPay 的双视角实测（AIHOT 11-27 早间精选，落在窗口内）。据 AIHOT 摘要：SkillPay 今年 7 月上线，支持买断与订阅两种售卖——买断定价 0.01–50 元、Skill 完整内容交付到买家本地；订阅按周/月/季度收费（上限 50 元），Skill 保留在云端沙盒执行、Agent 侧看不到明文，免费试用最低 5 次。文内给出从签约、定价到收款的上架流程。

以上价格与交付细节来自 AIHOT 摘要转述，公众号原文本期待进一步核验，数字未逐条独立证实。

为什么推给你：这是国内第一个把「Agent Skill」当作标准商品、且自带支付与交付闭环的平台，和你的 FDE 交付形态（卖账号+培训、利润向 token 转售与分润迁移）直接可比。「买断交付本地、订阅云端沙盒」两种模式恰好对应你在客户侧「能力留在哪、能不能撤回」的老问题。建议亲自跑一次最小上架：把一条现成 skill 挂 0.01 元买断，验证签约门槛、分成比例与交付体验，再判断是否值得把客户培训产物做成 SKU。
